React re-render cascade, measured

Every number on this page came out of running React 19.2.8 in Node, mounting the tree, firing one state change, and counting which component functions React called. Nothing here is written from memory, and each optimisation that is claimed to prevent a render is shown next to a run where the same optimisation does not.

  • 23 scenarios
  • 29 recorded state changes
  • 124 component verdicts
  • 53 measured re-renders
  • 71 measured skips
  • react-dom 19.2.8

Where the intuition is wrong

Each pair below differs by one line of code. The counts are the real ones.

React.memo, defeated by one inline object

The memo is on the component either way. Adding style={{ padding: 8 }} at the call site turns it off.
